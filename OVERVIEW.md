Inbox puts everything that is waiting on you into one screen: tool permission requests, plans and questions from agents, and agents that failed. Answer a request in one press, or open the agent. Below the queue, a Running section lists agents that are working right now, and a Done section lists agents that finished in the last 24 hours, newest first. Host tiles at the top pick which daemon to show, with a badge for what waits there. The Agents | Workspaces switch regroups both lists into one row per workspace, with its waiting and running counts and a button to open it.

It polls the daemon every couple of seconds, so a request shows up as soon as an agent asks. The sidebar row shows how many items are waiting.

Requires Paseo 0.11.4 or later. Error items clear when you open the agent.
